# Калибровка измерений

## Задача

Тестер показывает не только напряжение, но и сопротивление линий данных.
Измерять его напрямую нечем — в схеме нет ни образцового резистора на линии,
ни источника тока. Единственный доступный инструмент — **внутренняя подтяжка
RP2040**: если подать её на измеряемую линию, по установившемуся напряжению
можно восстановить внешнее сопротивление.

```
   R = Rpullup * V / (Vcc - V)
```

Беда в том, что `Rpullup` у RP2040 не нормирован точно: паспорт даёт разброс
примерно 40–80к, и у каждой платы он свой. Плюс АЦП не идеален. Если взять
паспортные 50к и ровно 3,3 В, ошибка выходит в разы.

## Решение: два известных резистора

На плате уже есть **два резистора с известным номиналом**, и оба висят на
АЦП-пинах:

| Резистор | Пин | Номинал |
|---|---|---|
| эталонный | GP29 | 10к на землю |
| нижнее плечо делителя VBUS | GP26 | 100к на землю |

Это даёт **две точки** и, соответственно, два уравнения — значит можно найти
сразу **два** неизвестных: сопротивление подтяжки и реальное напряжение её
шины.

Измеряем напряжение на каждом из них при включённой подтяжке:

```
v10  = Vcc * 10  / (Rpu + 10)
v100 = Vcc * 100 / (Rpu + 100)
```

Делим одно на другое и решаем систему:

```
Rpu = 54900 Ом
Vcc = 3.95 В
```

Полученные значения подставляются в формулу сопротивления. Прошивка делает
это сама при старте и печатает результат в Serial:

```
cal: Rpu=59682 ohm  Vcc=4.053 V  (v10=0.596 v1=2.950 vbus=4.78)
```

## Про получившееся «Vcc = 4 В»

Шина подтяжки питается от 3,3 В, там физически не может быть четырёх вольт.
Это не ошибка расчёта, а следствие того, что АЦП и внутренняя подтяжка не
подчиняются простой модели «резистор к питанию»: подгонка выкручивает
параметр, чтобы попасть в две известные точки.

Практический смысл в том, что **в диапазоне между этими двумя точками
результат получается верным**: модель, подогнанная по 10к и 100к, честно
считает и промежуточные номиналы вокруг 15–25к, то есть именно тот диапазон,
который встречается на линиях USB.

## Проверка

Живой тест: вместо щупа на линию D− припаивается резистор **15к**, и тестер
показывает **16к** — ровно 15к плюс последовательный 1к в линии.

На другом порту тестер показал 24к вместо ожидаемых 16к. Ошибки здесь нет:
у того порта действительно другие подтяжки.

## Когда калиброваться

Лучше всего — при **воткнутом щупе в живой порт** или **вообще без щупа**.
Прошивка различает три случая по состоянию линии VBUS:

| `vbus` | Ситуация | Что видит GP26 |
|---|---|---|
| > 0,3 В | щуп в живом порту | верхнее плечо сидит на VBUS, ветка учитывается |
| < 0,03 В | щуп в мёртвом порту | оба плеча грузят пин |
| между | щуп не воткнут | только нижнее плечо 100к |

Во всех трёх случаях система решается корректно.

## Точность

| Что | Насколько точно |
|---|---|
| Напряжение VBUS | делитель работает по соотношению, оно верное при любых одинаковых резисторах |
| Классификация линий (пусто / хост / устройство / КЗ) | надёжна, пороги разнесены широко |
| Абсолютное сопротивление | точное в диапазоне 10к–100к при откалиброванной подтяжке |
| Сопротивление вне этого диапазона | оценочное |
