# Протокол экрана G-Tag

Драйвер не написан на глаз: последовательность команд, формат слов и тайминги
сверены с записью логического анализатора, снятой с **штатной прошивки
ценника** в проекте
[lukdut/gtag-nrf-display](https://github.com/lukdut/gtag-nrf-display), файл
`docs/lcd-protocol-review.md`.

## Интерфейс

От платы к экрану идут **четыре сигнала**:

| Сигнал | GPIO |
|---|---|
| RESET | GP8 |
| CS | GP9 |
| CLK | GP10 |
| DIO | GP11 |

`DisplayCLK` (~28,8 кГц) и питание экрана даёт сама плата ценника. Прошивка
этот сигнал не формирует. `TE` в этой модели не используется.

## Передача слова

Каждое слово — **9 бит**: первый бит признак «команда или данные», затем восемь
бит данных, старшим вперёд.

```
CLK в покое низкий
CS опускается
устанавливается бит D/C
данные выставляются при низком CLK
CLK поднимается — данные защёлкиваются
... и так девять раз
CS поднимается после КАЖДОГО слова
```

Полупериод CLK — около 2 мкс, то есть примерно 250 кГц. Чтобы было понятно,
насколько это «медленно» и надёжно: у записанного оригинала период гулял в
пределах 3,5–4,25 мкс, так что мы укладываемся в тот же коридор.

## Последовательность инициализации

| Этап | Слова | Пауза после |
|---|---|---|
| `11` — выход из сна, затем очистка всех 16 страниц по 256 байт значением `FF` | 4161 | 10 мс |
| `4C 0C 00 00 00` — именно **четыре** байта данных | 5 | 4 мс |
| `4D FF 00 7F` | 4 | 1 мс |
| `4E 60` | 2 | 500 мс |
| **итого** | **4172** | |

## Вывод кадра

```
2A 00 00   — адрес 0
2C         — запись в память
4096 байт  — сам кадр
```

Итого 4100 слов.

## Формат кадра

Кадр — 4096 байт, по биту на пиксель.

```
индекс байта = y * 32 + x / 8
бит          = x % 8
значение 1   = белый
```

Разрешение 256×128.

Счётчик слов — независимая проверка: он не зависит от того, как выглядит
картинка. В нашей реализации он выводит в Serial:

```
init total   779 ms   4172 words  exp 4172 OK
frame        210 ms   4100 words  exp 4100 OK
```

Значит в панель уходит ровно тот же поток слов, что и у штатной прошивки
ценника, вплоть до количества.
